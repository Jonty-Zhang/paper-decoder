## 1. 定位与篇幅

解读是读完译文之后的“讲给你听”：把论文的关键部分和背后的原理讲透，并告诉读者怎么读原文、怎么复现、还能往哪做。它不是摘要，也不重复译文。

- 篇幅约等于原文正文页数（不算参考文献和附录）。正文 8 页的论文写 8–9 页，10 页的写 10 页左右。
- 10–15 张图，平均每页 1–2 张，不能是满页文字。
- 文件是 `<name>_interp.tex`，整体包在 `\begin{interp}{论文解读}` … `\end{interp}` 里，渲染脚本把它原样接在参考文献之后（`interp` 环境自带换页）。

## 2. 章节模板

按下面的顺序组织，章节名可以按论文调整，编号用“一、二、三……”。`examples/vggt2_interp.tex`（10 页 15 图）和 `examples/mast3r_interp.tex`（9 页 13 图）是完整范例。

| 节 | 内容 | 常配的图 |
|---|---|---|
| 一、这篇论文在解决什么问题 | 一句话概括（加粗）；当时存在什么问题；本文的核心做法 | 输入输出示意图、整体思路图 |
| 二、逐节导读 | 一张表：原文章节 / 这一节讲什么 / 读的时候抓住什么 / 难度（低中高）；表后给建议的阅读顺序 | 表格 |
| 三、背景或核心思想 | 读懂方法必需的背景（依赖的模型、前作的问题） | 前作的问题示意、概念示意 |
| 四～七、方法各模块 | 每个创新点一节：问题 → 做法 → 为什么这样做有效；每节配一张图 | 流程图、因子图、数值示例图 |
| （公式） | 每条公式的解释已经写在正文右栏、紧挨着公式（见 `translation.md` 的“公式解释”），解读里不再单列一节逐个讲。需要跨公式的整体推导或数值演示时，放进对应的方法章节 | 几何示意、函数曲线 |
| 实验结果怎么读 | 把原文的表重新画成图；指出比较时要注意的条件（有无标定、数据集特点）；逐序列看谁强谁弱；耗时拆分 | 条形图、分组柱状图 |
| 局限，以及可以做的方向 | 作者列出的局限逐条展开，每条给一个可动手的方向；最后用 `\keypt` 框出一个值得尝试的想法 | —— |
| 在技术线上的位置 | 和同方向代表作的对照表；技术演进时间线 | 时间线、对照表 |
| 常见疑问 | 5–7 个读者真会问的问题，每个“问：……”加粗，后面直接回答 | —— |
| 复现要点 | 代码地址、许可证、环境版本（Python、PyTorch、CUDA）、显卡要求、运行命令、建议亲手做的实验 | —— |

按读者调整：用户说过自己的研究方向时，在“局限”之后加一节“和你的课题怎么对接”：这篇论文的哪些模型、参数、结论能直接用，还缺什么，可以做什么题目，并配一张示意图；只引用原文的数字，推断的部分写明是自己的分析。用户说复现时再问、不要复现章节时，去掉“复现要点”。

## 3. 配图

所有图用 TikZ / pgfplots 现画，不从原文截图。

- **示意图**：流程、结构、几何关系（反投影、射线夹角、因子图、平面退化）。节点用圆角矩形，文字放在框里或框的左上角，避免椭圆套椭圆时文字重叠。
- **数据图**：原文表格里的数字重画成条形图或柱状图，一张图只讲一件事（例如“有无闭环的误差对比”），图题写明数据出自原文哪张表。
- **数值例子图**：用自己构造的例子演示原理（中位数抗离群值、加权平均的收敛、Huber 与平方误差），图题或正文里说明是假设的例子。
- **灰度**：填充只用 `black!10` 到 `black!85`，同一张图里相邻的系列灰度差 30 以上，黑白打印能分清。
- **图题**：`\tucap{图 N\quad 说明文字}`，编号全文连续；正文里引用自己的图写“图 N”，引用原文的图写“原文图 N”。

## 4. 写法

- 讲原理而不是复述：每个设计都回答“不这样做会怎样”。
- 所有数字出自原文；自己算的（平均值、百分比、例题）写完再验算一遍。正文里引用图中的数字要和图一致。
- 提到原文中的位置用“原文第 3.2 节”“原文表 5”；提到解读自己的章节用“第五节”。改动章节顺序后，全文搜索“第…节”“图 N”同步修改，`<name>_notes.txt` 里指向解读的引用也要改。
- 可以有自己的判断（比如“平面场景仍然是弱项，论文正文没有讨论这一点”），但要有原文数据支撑。
- 不写开场白和总结套话，第一节直接进入正题。

## 5. 可用的宏

定义在 `assets/preamble.tex`：

| 宏 | 用途 |
|---|---|
| `\begin{interp}{论文解读}` | 解读环境：换页、居中大标题、10.3pt 正文、首行缩进 2 字 |
| `\isec{一、标题}` | 一级标题 |
| `\isub{1. 标题}` | 二级标题 |
| `\tucap{图 N\quad 说明}` | 图题，放在图的 `center` 环境里、图的下面 |
| `\keypt{…}` | 灰底框，放“一个值得尝试的想法” |
| `ate labels` | pgfplots 选项：柱顶数字固定三位小数（0.030 而不是 0.03），用于误差类数据 |
| `ate labels2` | 同上，固定两位小数。原文表格只给两位小数时用它，柱顶数字的位数要和原文一致 |
| `\Needspace{16\baselineskip}` | 放在紧跟着图的 `\isub` 之前，剩余空间不够时把标题和图一起挪到下一页（`\isec`、`\isub` 自身只保证下面放得下几行文字） |

节标题后面紧接着就是一张图时，把 `\Needspace{20\baselineskip}` 放在 `\isec` 前面，防止标题孤零零落在页底。

## 6. pgfplots 与 TikZ 的坑

- 符号坐标里有英文括号时要加花括号：`(0.074,{VGGT-SLAM Sim(3)})`，否则编译报错。
- 柱状图图例用 `area legend`，否则图例里会画成两根小柱子。
- 数字格式全局已设为定点、最多三位小数、不加千位分隔（`1248` 不会变成 `1,248`，`0.03` 不会变成科学计数法）。误差类数据再加 `ate labels` 补零。
- 相对坐标在 axis 环境里要带单位：写 `([xshift=-22pt]axis cs:k1,0.85)`，不要写 `++(-22pt,0)`，后者的 `0` 会被当成符号坐标而报错。
- 图例容易挡住最高的柱子：图例放到图外上方 `legend style={at={(0.5,1.03)},anchor=south,legend columns=3}`，或调高 `ymax`。
- 柱子很密、标签互相重叠时，标签竖排：`nodes near coords style={font=\scriptsize,rotate=90,anchor=west}`。
- 标注文字不要加白底 `fill=white`，会盖住旁边的柱子；放到图外（`clip=false` 加 `node[right]`）更清楚。
- 数值不存在（比如某方法在某场景失败）时直接不画这一根柱子，再用一个文字标注说明原因，不要画成 0。
- 中文放在 TikZ 节点里没问题；多行用 `align=center` 加 `\\`。

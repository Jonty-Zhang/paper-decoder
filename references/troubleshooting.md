# 常见问题

按流程顺序排列，都是实际遇到过的。

## 锚定（anchor.py）

**段落锚定失败**
- 段落以公式开头：脚本会用公式前后的文字拼模式，仍失败时手工指定。
- 正式版与 arXiv 版措辞不同：换成与 HTML 同源的 arXiv 版 PDF，或手工指定。
- 手工指定：在 `<name>_lines.json` 里按页码找到这一段第一行，记下 `y0`；`band` 是 `<name>_layout.json` 里该页包含这个 y 的带的序号；`col` 是 `L`、`R`，跨栏带写 `F`。写进 `<name>_anchor_override.json`：`{"B4": {"page": 0, "band": 1, "col": "L", "y": 538.8}}`，页码从 0 数。

**图表题锚定失败**：脚本先按图表题正文匹配，失败再按“Table 4”“Fig. 3”“TABLE II”这样的编号标签匹配。几张子表共用一个块、主标题为空时，用第一个子标题定位。仍失败就手工指定。

**顺序倒挂**：图表题排在正文前面一般是浮动体造成的，属正常；如果两个相邻段落倒挂，多半是匹配到了别处的同一句话，手工指定后一段。

## 版面分析（layout.swift）

**一整页被判成一个跨栏带**：页边的竖排水印（arXiv 编号）会被当成横跨中缝的内容。脚本只扫描页宽 6.5%–93.5% 的区域来避开它；如果某篇论文的水印更靠里，调整 `layout.swift` 里的 `0.065` 和 `0.935`。

**页码被当成一个跨栏带**：高度小于 20 pt 且没有挂任何块的带会被自动跳过。

## 渲染与编译

| 现象 | 原因与修法 |
|---|---|
| `Undefined control sequence` 指向 `\par我们` | 中文字符紧跟在控制序列后面会被当成命令名的一部分。控制序列后面加空格或 `{}` |
| 中文里出现半角逗号、冒号、括号 | 渲染脚本会自动转换；仍残留的多半在 `**粗体**` 或公式旁边，直接在译文里写成全角 |
| pgfplots 报 `the input coordinate ... has not been defined with symbolic coords` | 符号坐标含英文括号要加花括号 `{Sim(3)}`；或相对坐标 `++(-22pt,0)` 里的 `0` 没带单位，改成 `([xshift=-22pt]axis cs:…)` |
| 参考文献每页只有一两条、页数暴增 | `multicols` 里不能用 `\offinterlineskip`，它会让 multicol 找不到分栏点 |
| `Overfull \vbox (1700pt too high)`，参考文献后面丢了几条、多出空白页 | 某一栏几乎是空的（比如最后一页只有左栏），很窄的切片被放大到栏宽后高度爆炸。`refstrips` 会跳过宽度小于 100 pt 或没有文字的栏 |
| 整页讲解的内容在页面上垂直居中 | preamble 里已把 `\@fptop` 设为 0；如果自己改了 preamble，保留这一行 |
| 图表里数字变成 `3·10^-2` 或 `1,248` | preamble 已全局关掉科学计数法和千位分隔；如果在单张图里覆盖了 number format，记得带上 `fixed` 和 `1000 sep={}` |
| 柱顶数字显示 0.03、0.1 | 误差类图表加 `ate labels` |
| 小节标题落在页底、图在下一页 | 在 `\isub` 前加 `\Needspace{16\baselineskip}`；节标题后紧跟小节再跟图时，把 `\Needspace{20\baselineskip}` 放在 `\isec` 前 |
| `render.py` 报缺少译文 | 按列出的块号补齐 `<name>_zh.txt` |

## 检查时容易漏的

- 解读改动章节顺序后，注释里“解读第 N 节”的引用没同步。
- 整页讲解超过一页：编译不报错，只在日志里留一条 `Float too large`，内容溢出到页外，必须看渲染图。
- 表格译文：原表格用颜色标最好/次好时，中文表只保留粗体和下划线；这是有意的简化，不用补颜色。

## 1. 文件格式

`<name>_zh.txt` 每块一行，块号与 `<name>_src.txt` 一致：

```
B6|||I 引言
B7|||近来，在机器人与计算机视觉领域……
B49.s0|||(a) 来自 Clio [40] 公寓场景的示例图像。键 token 放在一面纯色墙上。
```

- 一块一行，段内不要换行。
- 行内公式占位符 `⟦M12⟧` 必须原样保留，个数和顺序都不能变，渲染时换回原文的 LaTeX。可以按中文语序挪动位置。
- 原文的粗体 `**…**` 保留；脚注上标写成 `^1^`。
- 引用编号 `[12]`、`[5, 42]` 按 `<name>_src.txt` 原样保留。HTML 与 PDF 编号不同时由渲染脚本统一改成 PDF 的编号，翻译时不用管，也不要为此加译注。
- 参考文献、作者名不需要翻译，脚本会原样使用。
- 行间公式不翻译，但每一条都要写解释，见下文“公式解释”。

## 2. 各类块怎么译

| 块 | 写法 | 例 |
|---|---|---|
| 论文标题 [H1] | 全译，保留系统名 | `MASt3R-SLAM：基于三维重建先验的实时稠密 SLAM` |
| 章节标题 | 保留原编号（罗马数字、`IV-A`、`3.2` 都照抄），后接中文 | `IV-A 相对帧对齐`、`3.2 点图匹配` |
| “Abstract” | `摘要` | |
| 图题、表题 | 按原文标签写“图 N：”“表 N：”，IEEE 的罗马数字表号照抄 | `图 3：……`、`表 I：……` |
| 子图题 | 保留 `(a)` `(b)` | `(b) 没有重叠的查询帧与检索帧。……` |
| 段落段首的粗体小标题 | 保留粗体 | `**符号。** 我们用粗体字母表示……` |
| 列表项 | 正常翻译，脚本自动加项目符号 | |

## 3. 术语与口吻

- 先把整篇读完再译，同一个术语全文用同一个译法。
- 术语第一次出现写成“中文（English）”，之后只用中文；已经约定俗成用英文的（SLAM、token、GPU、ATE 等）保留英文。
- 方法名、系统名、数据集名、序列名不译：VGGT-SLAM、TUM RGB-D、floor、room。
- 口吻是准确、通顺的学术中文。原文的长句按中文习惯拆开，不逐词硬对；不增删信息，不加解释性的话（解释放进概念注释）。
- 作者自称 “we” 译作“我们”；“Ours” 在正文中译作“我们的方法”，在表格里译作“本文”。

## 4. 标点

中文用全角标点。直接写全角最好；写成半角也行，渲染脚本会把中文语境里的 `, : ; ( )` 自动换成全角，但数字中的逗号（`4,200`）、引用编号里的逗号、网址、紧跟在英文后的短编号括号 `(a)` 会保持半角。英文双引号 `"…"` 会被成对换成中文引号。

## 4.5 公式解释

`<name>_src.txt` 里类型为 `[式 (n)]` 的行是行间公式，后面是它的 LaTeX。公式本身没什么可翻译的，所以右栏不再重抄公式，而是在同一位置写一段解释：

```
B76|||逆运动学的思路是“先把已知的部分除掉”。式 (9)：期望的尖端位姿 ${}^{b}T_{t}^{*}$ 左乘手臂和适配器两段的逆矩阵……式 (10)：……
```

- 讲清三件事：这条公式在算什么；每个符号代表什么（尤其是原文没在附近交代的）；为什么要这样写，不这样会怎样。
- 复杂的公式（矩阵、多项求和、带约束的优化）要具体：说明矩阵每一块或每一行的含义，代入原文给出的数字举例，例如“表 II 中 $l_{P2Y}=0.0091$ m，约 9 mm”。
- 一个块里有几条公式（如 `[式 (9)–(10)]`）时，按式号分开讲。
- 可以直接写 `$…$`，不用占位符。数字只用原文给的；自己举的例子要说明是假设。
- 篇幅一般 2–5 句。简单的定义式一两句即可，不要为凑字数复述译文。
- 渲染时标签“式 (n)”自动加在开头，解释里不用再写。

## 5. 译注

只在原文确有错误或前后不一致时加，格式 `【译注：……】`，写清楚哪里和哪里对不上，放在出问题的句子后面。渲染时显示为灰色斜体。例子：

```
【译注：正文第 V-E 节写 Kitti 场景包含 44 个子图，与此处的 42 不一致，原文如此。】
【译注：按下方表题，匹配方法的比较是表 4，表 5 是融合方法，原文此处编号疑有误。】
```

一篇论文通常只有 0–3 条。不要用译注发表评论、补充背景或提示“翻译可能不准”。

## 6. 表格译文

`tables.py` 生成的 `<name>_tables_zh.txt` 每行 `原文 ||| 译文`，同一个原文字符串在所有表格里共用一条。

| 类型 | 做法 | 例 |
|---|---|---|
| 表头、行名 | 译成中文 | `Accuracy ||| 准确度`、`Calibrated ||| 已标定` |
| 单位 | 译成中文放全角括号里 | `ATE [m] ||| ATE（米）`、`Time [ms] ||| 耗时（毫秒）` |
| 缩写指标 | 保留缩写，必要时加中文 | `FPS ||| 帧率（FPS）` |
| “Ours” 系列 | `本文`、`本文*`、`本文 + 特征精修` | |
| 方法名（含引用）、数据集名、序列名 | 原样照抄 | `DROID-SLAM [20] ||| DROID-SLAM [20]` |
| 公式 | `$…$` 保留，只译外面的文字 | `$k$-d tree ||| $k$-d 树` |

右边留空的行按原文输出，所以漏填不会报错，但交付前应当全部填上。

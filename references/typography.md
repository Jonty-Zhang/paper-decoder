# 版式参数

全部定义在 `assets/preamble.tex`，渲染脚本每次都从这里读取。改这里就改了所有论文的版式。

## 页面

| 项目 | 取值 |
|---|---|
| 纸张 | A4，单面 |
| 页边距 | 上 14 mm，下 16 mm，左右各 13 mm |
| 双语栏 | 左右各 `0.5\textwidth − 6pt`（约 90 mm），中间一条 0.4 pt、25% 灰的竖线 |
| 原文切片 | 矢量裁切（`\includegraphics` 的 viewport），左右各留 3 pt，宽度缩放到栏宽，所以原文与原版字号基本一致 |

## 字体

| 用途 | 字体 |
|---|---|
| 西文正文 | Times New Roman |
| 中文正文 | 宋体（Songti SC，粗体用 Songti SC Bold） |
| 中文标题、注释术语、表头 | 黑体（Heiti SC） |

## 字号（字号 / 行距）

| 位置 | 字号 |
|---|---|
| 译文正文 | 9.3 pt / 14 pt |
| 译文里的论文标题 | 14 pt 粗体居中 |
| 译文里的二级、三级标题 | `\large`、`\normalsize` 粗体 |
| 中文图表题 | `\small`，85% 黑 |
| 中文表格 | 8 pt / 10 pt，列间距 3.5 pt，超宽时整体缩到栏宽 |
| 概念注释 | 8.4 pt / 12.6 pt；框标题“概念注释”黑体 `\small` |
| 整页讲解 | 9.6 pt / 15.5 pt，段间距 4 pt |
| 解读正文 | 10.3 pt / 17.5 pt，首行缩进 2 字，段间距 2 pt |
| 解读大标题“论文解读” | 20 pt 黑体居中 |
| 解读一级 / 二级标题 | 黑体 `\Large` / `\large` |
| 解读图题 | `\small` 居中 |

## 框与颜色

全部用灰度，黑白打印可读。

| 元素 | 样式 |
|---|---|
| 概念注释框 | 边框 60% 灰、0.6 pt，底色 5% 灰，内边距 4.5 pt |
| 整页讲解标题条 | 80% 灰底，白色黑体 `\large` “延伸讲解　标题” |
| 解读里的重点框 `\keypt` | 边框 70% 灰，底色 4% 灰，内边距 6 pt |
| 译注 | 70% 灰斜体 |
| 数据图 | 填充 `black!10`–`black!85`，线条黑色 |

## 版面规则

- 每个段落的原文切片从这一段第一行的上沿开始，到下一段第一行的上沿为止；译文放在切片右边，第一行齐平。
- 跨两栏的图表（整行带）原样放一整行，下面接中文图表题、中文表格，再接注释。
- 一栏顶部从上一栏延续下来的半段文字单独成一条切片，右边留空。
- 注释框先试着放在右栏译文下方（译文加注释的总高度小于左边切片的高度时）；放不下就占满页宽接在这一行后面。
- 整页讲解是 `figure[p]` 浮动页，顶端对齐，出现在所挂段落之后的第一个可用位置。
- 参考文献按原文阅读顺序（左栏 → 右栏 → 下一页）在行间空隙处切成约 110 pt 高的小条，用两栏 `multicols` 重新排；最后一页的空栏不输出。
- 解读另起一页。

## 单栏论文的版面

- 原文切片保持原大（不缩放），横向范围取正文栏的左右边界各放宽 12 pt，整体居中；译文、注释框、中文表格和它同宽（`flowcol` 环境）。
- 每一组依次是：原文切片（多块时无缝衔接）→ 间隔 4 pt → 译文（9.3 pt / 14 pt，可以跨页）→ 注释框 → 页脚注切片 → 间隔 8 pt。
- 文字切片在行间空白处切成约 110 pt 高的小段，图表块不切。
- 每组开头用 `\Needspace` 保证本页至少放得下第一块切片再加两行；标题组还要多留约 90 pt，避免标题落在页底。
